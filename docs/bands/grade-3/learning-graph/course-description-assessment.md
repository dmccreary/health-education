# Course Description Quality Assessment — Grade 3

## Source Document

[docs/bands/grade-3/course-description.md](../course-description.md)

## Summary

The Grade 3 course description is a well-structured, standards-traceable
document derived from the 2025 Minnesota K-12 Health Academic Standards. It
enumerates 27 benchmark-coded topics across five content strands (Food and
Nutrition, Human Growth and Development, Mental and Emotional Health,
Personal Health and Wellness, Personal Safety and Violence Prevention) plus a
cross-cutting Skill Standards group, and organizes learning outcomes using
the 2001 Bloom's Taxonomy (Remember, Understand, Apply, Analyze, Evaluate —
with Create still deliberately thin/absent per the developmental design of
the K-12 standards, explicitly documented in the text rather than an
oversight).

Grade 3 is a meaningful developmental step up from Grade 2: it introduces the
first genuine **Evaluate**-level benchmarks (evaluating personal behaviors to
prevent injuries; determining validity/reliability of health information)
and the first explicit mention of **puberty** as a body-change topic. This
assessment evaluates the description against a right-sized concept target of
approximately 55-60 concepts, not the skill's generic 200-concept default,
which would force invented content not grounded in the standards.

## Strengths

- Every topic traces to a specific MDE benchmark code, giving the learning
  graph strong provenance.

- Clear five-strand + Skill Standards structure maps cleanly onto the same
  taxonomy scheme used for Kindergarten, Grade 1, and Grade 2, supporting
  cross-band comparability.

- Key Vocabulary section (16 terms) gives ready-made concept candidates.

- Explicit "Bridging Concepts for Students New to This Band" section
  clarifies which K-2 ideas are assumed but not re-taught.

- First appearance of genuine Evaluate-level outcomes (injury-prevention
  evaluation across environments; validity/reliability determination of
  health information) shows a documented, deliberate developmental
  progression from Grade 2's single evaluative foothold.

- First explicit introduction of puberty as a body-change topic, clearly
  scoped to "recognizing stages" and "asking for help," appropriate for the
  8-9 age band.

## Gaps

- No dedicated "Topics Excluded" section (partial credit given based on
  related context elsewhere in the document).

- Apply and Analyze outcomes are present but modest in count, reflecting the
  developmental level of the band rather than a document defect.

- Create-level outcomes remain explicitly deferred to Grade 4, which is
  appropriate for this band but caps rubric points under a generic scoring
  template designed for adult/higher-ed courses.

## Concept Count Guidance

Per explicit run-level override, this band targets approximately 55-60
concepts (not 200), built only from the 27 enumerated benchmarks, the 16 key
vocabulary terms, and a small number of clearly-implied bridging/connective
concepts. This is appropriate given the describe/explain-plus-emerging
evaluate scope of Grade 3 health standards, and keeps the graph comparable in
density to the Kindergarten (45-concept), Grade 1 (55-concept), and Grade 2
(55-concept) bands.
