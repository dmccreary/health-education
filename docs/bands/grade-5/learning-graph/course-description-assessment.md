# Course Description Quality Assessment — Grade 5

## Source Document

[docs/bands/grade-5/course-description.md](../course-description.md)

## Summary

The Grade 5 course description is a well-structured, standards-traceable
document derived from the 2025 Minnesota K-12 Health Academic Standards. It
enumerates 31 benchmark-coded topics across five content strands (Food and
Nutrition, Human Growth and Development, Mental and Emotional Health,
Personal Health and Wellness, Personal Safety and Violence Prevention) plus a
cross-cutting Skill Standards group — the richest topic set of the K-5
bands — and organizes learning outcomes using the full 2001 Bloom's Taxonomy
(Remember, Understand, Apply, Analyze, Evaluate, Create). This assessment
evaluates the description against a right-sized concept target of
approximately 65-70 concepts, not the skill's generic 200-concept default,
which would force invented content not grounded in the standards.

Grade 5 is the last individually-graded band before the 2025 Minnesota
standards shift to multi-grade spans (6-8, 9-12), and the document notes
this explicitly. It also introduces the first genuine **consent and
coercion** language, the first explicit **equity and belonging** vocabulary
tied to ability-inclusive treatment, and continues the comparison/analysis
emphasis (comparing nutrition labels, comparing cultural approaches to
nutrient needs) that began developing in Grade 4.

## Strengths

- Every topic traces to a specific MDE benchmark code, giving the learning
  graph strong provenance.

- Largest and most granular topic set of any K-5 band (31 benchmark-coded
  topics), reflecting Grade 5's role as the capstone of individually-graded
  elementary standards.

- Strongest Evaluate-level tier of the K-5 bands (5 outcomes), reflecting
  the band's shift toward middle-school-style judgment and comparison
  (evaluating relationship safety, technology harm, resource selection).

- Introduces new, more mature vocabulary not seen in earlier bands: consent,
  coercion, equity, belonging, bystander, fitness component — each mapping
  to a specific benchmark.

- Clear five-strand + Skill Standards structure maps cleanly onto the same
  taxonomy scheme used for Kindergarten through Grade 4, supporting
  cross-band comparability.

- Explicit "Bridging Concepts for Students New to This Band" section
  clarifies which K-4 ideas are assumed but not re-taught.

- Explicitly documents its own status as the last individually-graded band
  before the standards shift to grade spans, an important structural marker
  for the whole K-5 sequence.

## Gaps

- No dedicated "Topics Excluded" section (partial credit given based on
  related context elsewhere in the document).

- Remember-level outcomes are limited to a single outcome, the thinnest
  Remember tier of any band generated so far — though this reflects Grade
  5's developmental shift toward comparison/application rather than rote
  recall, not a document defect.

- Create-level outcomes are thinner than Grade 4's (1 vs. 3), reflecting
  that most of Grade 5's higher-order benchmarks land at Analyze/Evaluate
  (comparison, judgment) rather than Create (synthesis/production).

- The course description contains an explicit inline note that its Personal
  Health/Wellness and Personal Safety strand benchmarks were sampled and
  should be double-checked against the primary source. Per this run's
  instructions, the content actually present in the file is treated as
  authoritative and complete for concept-graph generation; no additional
  benchmarks were invented to compensate.

## Concept Count Guidance

Per explicit run-level override, this band targets approximately 65-70
concepts (not 200), built only from the 31 enumerated benchmarks, the 13 key
vocabulary terms, and a small number of clearly-implied bridging/connective
concepts. This is appropriate given Grade 5's richer benchmark set (the
largest of the K-5 bands) and keeps the graph comparable in density and
structure to the Kindergarten (45-concept), Grade 1 (55-concept), Grade 2
(55-concept), Grade 3 (57-concept), and Grade 4 (58-concept) bands already
generated, while reflecting the larger source material with a
proportionally larger graph.
