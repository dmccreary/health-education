## About this MicroSim

**Cultural Lenses on Respect and Boundaries** is an interactive MicroSim for this health-education textbook.

Students analyze how individualist and collectivist orientations, and specific cultural concepts (reciprocity, filial respect, respeto), frame boundary-setting differently while protecting the same underlying need.

Use the controls in the panel below the drawing to interact with the model, then talk through what changed and why. The MicroSim is width-responsive and can be embedded in any course page with the iframe shown above.

**Bloom's Taxonomy level:** Analyze (L4) — compare, contrast, examine, differentiate

## Lesson Plan

### Audience

This MicroSim is designed for **Grades 6-8**. For the K-3 bands the teacher
typically drives the activity on a shared screen; older students can explore
the MicroSim independently.

### Learning Objective

Students analyze how individualist and collectivist orientations, and specific cultural concepts (reciprocity, filial respect, respeto), frame boundary-setting differently while protecting the same underlying need.

This activity targets **Bloom's Analyze (L4)** (compare, contrast, examine, differentiate).

### Suggested Use (about 10 minutes)

1. **Warm up (2 min).** Ask students what they already know about the topic
   and let one volunteer describe what they see on the screen.
2. **Model it (3 min).** Demonstrate the interaction once, thinking aloud so
   students hear the reasoning behind each choice.
3. **Guided practice (3 min).** Invite students to try the interaction and to
   predict what will happen before they act.
4. **Discuss (2 min).** Ask *why* the result came out the way it did, connecting
   the on-screen result back to the learning objective above.

### Check for Understanding

Have each student (or pair) explain their result in one sentence, using the
vocabulary from this chapter. Look for reasoning that matches the
**Analyze**-level objective rather than a lucky guess.

```text
Learning objective: Students analyze how individualist and collectivist orientations, and specific cultural concepts (reciprocity, filial respect, respeto), frame boundary-setting differently while protecting the same underlying need.

Layout: A central "Boundary Example" scenario (e.g., declining to share personal information) with four selectable lens cards: Individualist Orientation, Reciprocity, Filial Respect, Respeto.

Interactive elements: Click a lens card for an infobox on how that framework expresses the same boundary, plus its origin/emphasis; a "What's Shared" toggle restates that all four lenses protect a genuine limit, differing only in expression.

Instructional Rationale: Comparing frameworks and attributing differences to cultural values is Analyze-level, so a lens-based comparison anchored to one scenario is used, keeping the shared function of a boundary visible across expressions.

Implementation notes: p5.js. Each lens as an object with name, origin description, and example phrase; "What's Shared" is a static toggle.
```
