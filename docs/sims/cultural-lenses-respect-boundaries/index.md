```text
Bloom Taxonomy: Analyze (L4)
Bloom Taxonomy Verb: compare, contrast, examine, differentiate

Learning objective: Students analyze how individualist and collectivist orientations, and specific cultural concepts (reciprocity, filial respect, respeto), frame boundary-setting differently while protecting the same underlying need.

Layout: A central "Boundary Example" scenario (e.g., declining to share personal information) with four selectable lens cards: Individualist Orientation, Reciprocity, Filial Respect, Respeto.

Interactive elements: Click a lens card for an infobox on how that framework expresses the same boundary, plus its origin/emphasis; a "What's Shared" toggle restates that all four lenses protect a genuine limit, differing only in expression.

Instructional Rationale: Comparing frameworks and attributing differences to cultural values is Analyze-level, so a lens-based comparison anchored to one scenario is used, keeping the shared function of a boundary visible across expressions.

Implementation notes: p5.js. Each lens as an object with name, origin description, and example phrase; "What's Shared" is a static toggle.
```
