```text
Type: infographic

**sim-id:** punitive-vs-restorative-framework<br/>
**Library:** p5.js<br/>
**Status:** Specified

Bloom Taxonomy Level: Analyze (L4)
Bloom Verb: differentiate, compare, examine

Learning objective: Students differentiate the guiding questions,
processes, and goals of a punitive justice model from an Indigenous
restorative justice model, examining talking circles and peacemaking
circles as concrete practices within the restorative framework.

Layout: Two labeled columns, "Punitive Model" and "Indigenous Restorative
Model," each with four rows: Guiding Question, Who Participates, Process,
and Goal

Data Visibility Requirements:
  Stage 1: Show both columns with their four rows populated (Punitive:
  "What rule was broken and what punishment fits?" / single authority
  decides / hearing or disciplinary process / punishment); (Restorative:
  "Who was harmed and what do they need?" / affected community including
  the person harmed and person responsible / talking circle or peacemaking
  circle / repair and reintegration)
  Stage 2: Clicking "Talking Circles" or "Peacemaking Circles" (labeled
  buttons beneath the Restorative column) opens an infobox with a
  respectful, specific description of that practice drawn from the
  chapter text
  Stage 3: A prompt scenario (a conflict between two students) is shown,
  and the learner selects which questions each model would ask about it,
  reinforcing the guiding-question distinction

Interactive controls: Click any row label for an expanded explanation;
click "Talking Circles" / "Peacemaking Circles" buttons for practice
descriptions; button "Apply to Scenario" reveals how each model would
approach the sample conflict

Instructional Rationale: Differentiating two justice frameworks by their
guiding logic is an Analyze-level objective, so a structured comparison
with a scenario-application check is used rather than simple recall,
ensuring the restorative framework is presented with genuine substance
rather than a single sentence.

Implementation notes: p5.js; content written to present both frameworks
respectfully, with the restorative model described using its own
practices (talking circles, peacemaking circles) rather than defined only
in contrast to the punitive model.
```
