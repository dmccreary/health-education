## Specification

The full specification below is extracted from
[Chapter 4: Staying Healthy in Our Environment](../../bands/grade-2/chapters/04-staying-healthy-environment/index.md).

```text
Type: map
**sim-id:** cultural-physical-activity-map<br/>
**Library:** Leaflet<br/>
**Status:** Specified

Bloom Taxonomy: Understand (L2)
Bloom Taxonomy Verb: describe, exemplify, compare

Learning objective: Students describe examples of cultural and traditional physical activities from different communities and compare what makes each one active and meaningful.

Geographic scope: World map with five marked regions

Purpose: Show that active, traditional games and dances exist in communities all over the world, each with its own history

Locations and markers:
- Philippines: Tinikling dance marker
- North American Indigenous nations (general region marker, respectfully labeled by nation where possible): Powwow dance marker
- West Africa: traditional circle-dance marker
- Caribbean: jump-rope game marker (Double Dutch origins)
- General "your community" marker inviting students to think of a local tradition

Legend: Icons for "dance," "jump-rope game," and "group circle activity"

Interactive features:
- Click each marker to open an infobox with: name of the activity, a simple description, and one sentence on why it is physically active
- All markers presented with equally respectful, neutral description style -- no marker described as more "unusual" than another
- Button: "Show My Community" prompts students (via teacher discussion) to name a local tradition to add to the discussion

Color scheme: Each marker uses the same neutral gold color (matching mascot palette) so no single tradition is visually emphasized over another

Implementation: Leaflet map with custom marker icons and popups; simple world basemap with minimal extra detail so markers are the visual focus
```
