The full specification below is extracted from

```text
Type: infographic
**sim-id:** substance-free-benefits-explorer<br/>
**Library:** p5.js<br/>
**Status:** Specified

Bloom Taxonomy: Understand (L2)
Bloom Taxonomy Verb: explain, summarize, identify

Learning objective: Students identify and explain specific, concrete benefits of remaining substance-free across sleep, athletics, academics, relationships, and brain development.

Layout: A central figure icon representing "A Substance-Free Teen" with five surrounding labeled nodes: Sleep, Athletic Performance, Academic Focus, Relationships, Brain Development.

Interactive features: Clicking or hovering each node opens an infobox with two to three sentences explaining the specific, concrete benefit in that area, referencing the biological reasons established in the previous chapter (e.g., "Sleep: Alcohol, nicotine, and cannabis all disrupt healthy sleep cycles; a substance-free body gets full, restorative sleep that supports memory and mood"). A "See All Benefits" button reveals all five infobox texts stacked together as a printable-style summary.

Default state: No node selected; prompt reads "Click a topic to see how staying substance-free helps."

Color scheme: Warm, positive palette (greens and golds) to visually reinforce the positive framing of this section, distinct from the risk-focused color schemes used later in the chapter.

Implementation: p5.js with clickable circular nodes around a central figure; responsive canvas that rearranges nodes into a vertical list on narrow screens.
```
