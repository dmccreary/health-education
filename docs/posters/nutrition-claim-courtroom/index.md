Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **The Claim** — State exactly what the product or message promises.
2. **The Source** — Identify who created and paid for the message.
3. **The Evidence** — Look for relevant, transparent, and reproducible evidence.
4. **What Is Missing** — Ask about dose, population, alternatives, risks, and context.
5. **The Verdict** — Reach a cautious conclusion that matches the strength of evidence.
