Use **Explore** mode to select a marker or section and learn more. Use **Quiz** mode to practice finding each idea.

1. **Goal and Baseline** — Choose a meaningful goal and notice the current starting point.
2. **Endurance** — Endurance activities challenge the heart, lungs, and sustained movement.
3. **Strength** — Strength work helps muscles, bones, movement, and daily function.
4. **Mobility** — Mobility combines usable range of motion, control, and comfort.
5. **Recovery and Revision** — Rest, sleep, nutrition, hydration, and easier days support adaptation.
