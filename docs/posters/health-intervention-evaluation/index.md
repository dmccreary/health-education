Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **Reach** — Identify who participated, who did not, and why.
2. **Quality** — Assess whether the intervention was delivered as intended and respectfully.
3. **Outcomes** — Measure meaningful short- and long-term changes linked to the goal.
4. **Equity** — Compare access, experience, benefits, and burdens across groups.
5. **Unintended Effects** — Look for unexpected benefits, harms, displacement, stigma, or behavior changes.
