Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **Define the Issue** — Describe the health issue, affected people, causes, and desired change.
2. **Know the Audience** — Identify who can influence the decision and what they need to understand.
3. **Use Evidence** — Select credible facts and relevant lived experience.
4. **Make the Ask** — Request a specific feasible action and explain why it matters.
5. **Listen and Revise** — Invite feedback, notice missing voices, and improve the message or plan.

Teachers and editors can open [calibration mode](./main.html?edit=true) to adjust overlay positions.
