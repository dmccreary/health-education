Use **Explore** mode to select a section and learn more. Use **Quiz Me** mode to practice finding each idea.

1. **Calm First** — Pause and settle the body before trying to solve the problem.
2. **I-Statement** — Describe your feeling and the event without attacking the other person.
3. **Listen** — Active listening helps each person feel heard.
4. **Solutions** — Generate options that protect everyone’s needs and safety.
5. **Repair** — A repair action helps the relationship and problem recover.
