# Before You Send — Image Generation Prompt

Use case: infographic-diagram
Asset type: wide interactive educational poster base for Grade 3
Primary request: Create a polished four-stage visual journey showing a digital message traveling through thoughtful choices before sending.
Scene/backdrop: A beautiful oversized tablet-and-message studio viewed straight on, divided into four equal vertical panels connected by one glowing message bubble.
Required text (verbatim, headings only): "PAUSE", "CHECK PRIVACY", "CONSIDER IMPACT", "CHOOSE"
Subject details: PAUSE shows a hand hovering safely above a send button with a calm pause symbol; CHECK PRIVACY shows a photo card with neutral icons suggesting home location, school identity, and a friend, protected by a translucent shield; CONSIDER IMPACT shows two contrasting facial-expression reflections, prompting thought about tone and feelings; CHOOSE shows the message being saved, revised, shared with permission, or shown to a trusted adult using visual icons only.
Style/medium: ultra-polished children's technology editorial illustration, dimensional paper-cut and soft 3D hybrid, crisp typography, friendly not babyish.
Composition/framing: 1536×1024 wide landscape, exact four equal columns, bold heading centered at top of each column, strong visual hierarchy.
Color palette: midnight navy base with luminous cyan, mint, amber, and magenta accents.
Text constraints: Render exactly the four quoted headings, spelled correctly, and no other words anywhere.
Avoid: app logos, brand interfaces, readable private data, chat text, numbers, arrows, callout marks, watermarks, threatening strangers.
