[Open the interactive poster full screen](./main.html){ .md-button .md-button--primary }

Use **Explore** mode to hover over or select a numbered marker. Use **Quiz** mode to listen to or read a visual hint and find the matching place in the classroom.

The ten callouts are:

1. An Uncovered Cough
2. Germs Riding on Droplets
3. A Shared Doorknob
4. Shared Blocks
5. Germs on Hands
6. Touching the Face
7. Cough Into an Elbow
8. Tissue Into the Trash
9. Soap
10. Washing Hands

Teachers and editors can open [calibration mode](./main.html?edit=true) to drag the markers and copy updated coordinates.
