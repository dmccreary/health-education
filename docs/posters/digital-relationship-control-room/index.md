Use **Explore** mode to select a section and learn more. Use **Quiz Me** mode to practice finding each idea.

1. **Privacy** — Protect passwords, location, personal details, and image-sharing permission.
2. **Pressure** — Repeated demands, secrecy, and urgency can signal unhealthy control.
3. **Harm** — Online harm can include exclusion, rumors, impersonation, threats, or unwanted sharing.
4. **Report** — Reporting can connect evidence with adults, schools, platforms, or emergency help.
5. **Exit and Support** — Block, mute, leave, adjust settings, and connect with supportive people.
