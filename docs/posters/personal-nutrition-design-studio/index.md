Use **Explore** mode to select a marker or section and learn more. Use **Quiz** mode to practice finding each idea.

1. **Personal Needs** — Nutrition needs vary with age, health, activity, access, preferences, and goals.
2. **Label Evidence** — Labels help compare serving information, nutrients, and ingredients.
3. **Beverage Evidence** — Beverages can contribute hydration, nutrients, caffeine, sugar, or alcohol.
4. **Meal Timing** — Timing can interact with hunger, schedules, sleep, activity, culture, and medication.
5. **Cultural Traditions** — Cultural foods carry identity, connection, knowledge, and nourishment.
6. **Revise the Plan** — A useful plan changes when needs, evidence, resources, or results change.

Teachers and editors can open [calibration mode](./main.html?edit=true) to adjust overlay positions and copy updated coordinates.
