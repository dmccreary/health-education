# Growing Up: Everyone's Timeline Is Different — Image Generation Prompt

Please generate a new image.

## Production Prompt

An annotation-free, privacy-first Grade 3 panorama with ten non-anatomical growth moments: outgrown shoes, varied height timing, a confident shorter student, hygiene guidance, mixed emotions, peers at varied stages, parent questions, school helpers, health professional support, and equally bright parallel paths.

## Image Specifications

- Format: PNG
- Wide-landscape composition
- Audience: Grade 3 health education
- Overlay: numbered HTML callout markers

## Critical Constraints

The image must contain absolutely no text, labels, arrows, callout lines, numbers, title, or annotation marks. All labeling is supplied by the HTML overlay.
No logos, brands, signatures, or watermarks. Leave visual breathing room for the interactive overlays.
