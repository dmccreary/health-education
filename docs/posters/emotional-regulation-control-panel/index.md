Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **Name It** — Naming an emotion can make the experience easier to understand.
2. **Body Signals** — Notice breathing, tension, energy, temperature, stomach, and movement cues.
3. **Pause** — Create a small gap before acting when it is safe.
4. **Choose a Tool** — Select from breathing, movement, art, music, nature, grounding, or rest.
5. **Connect** — Co-regulation and support can help when feelings are intense.
6. **Reflect** — Review what triggered the feeling and what helped afterward.
