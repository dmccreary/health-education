Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **Read the Situation** — Assess safety, power, escalation, exits, and whether dialogue is appropriate.
2. **Lower the Heat** — Use calmer tone, more space, fewer spectators, and a pause when possible.
3. **Listen for Needs** — Listen for interests, fears, values, and unmet needs beneath positions.
4. **Create Options** — Generate choices that protect safety, dignity, and practical needs.
5. **Exit or Get Help** — Leave, set a boundary, or involve trusted adults, staff, or emergency help when unsafe.
