# Personal-Space Planets — Image Generation Prompt

Please generate a new image.

## Production Prompt

An annotation-free Grade 2 playground imagined as a solar system with nine interaction clusters and translucent personal-space orbit bubbles: ask before closeness, notice stepping back, mutual play, stop when a signal changes, different comfortable distances, wheelchair turning space, teasing interruption, repair, and trusted-adult help.

## Image Specifications

- Format: PNG
- Wide-landscape composition
- Audience: Grade 2 health education
- Overlay: numbered HTML callout markers

## Critical Constraints

The image must contain absolutely no text, labels, arrows, callout lines, numbers, title, or annotation marks. All labeling is supplied by the HTML overlay.
No logos, brands, signatures, or watermarks. Leave visual breathing room for the interactive overlays.
