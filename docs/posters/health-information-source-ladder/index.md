Use **Explore** mode to select a marker or section. Use **Quiz** mode to practice finding each idea.

1. **Expert Guidance** — Qualified professionals can apply training to a specific question.
2. **Public Health Source** — Accountable agencies can synthesize evidence and issue population guidance.
3. **Research Evidence** — Research can test claims systematically.
4. **Personal Story** — Lived experience provides meaning, context, and questions that data may miss.
5. **Ad or Influencer** — Promotional content may be engaging but has a goal and possible conflicts.
